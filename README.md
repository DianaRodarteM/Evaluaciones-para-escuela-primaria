# Evaluaciones-para-escuela-primaria
Se realizan JOINs y consultas SQL sobre una base de datos relacional de una escuela primaria.


En este proyecto se realizaron JOINs y consultas SQL sobre una base de datos relacional de una escuela primaria (grupos, alumnos, materias y calificaciones). Se crearon tablas con pandas, se guardaron en CSV y se cargaron en SQLite con llaves primarias y foráneas; después se usaron INNER JOIN, LEFT JOIN, CASE WHEN (aprobado/reprobado), subconsultas con AVG y GROUP BY (promedio por grupo) y filtros IN / NOT IN. 

Conclusiones: Los JOINs y subconsultas permiten integrar tablas separadas para analizar el rendimiento académico por alumno, materia y grupo.
